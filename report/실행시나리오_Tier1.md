# Tier 1 상위 지역 실행 시나리오

우선순위 상위 + "이미 워케이션형 체류" + 인구감소 심각을 만족하는 3곳을 예시로,
"진단 → 처방 → 분기 추적 KPI"를 구체화했다. 공통 전제: **89곳 모두 민간 공유오피스 0개**
→ 업무공간은 지자체가 조성해야 함.

## 1. 전남 완도군 — 우선순위 1위 (93.4)

**진단(데이터)**
- 2×2: 가속 워케이션형 / 체류질: 워케이션형 성장(추세+·안정)
- 체류 성숙도 **+0.97**(89곳 중 최상위권) · 성장 모멘텀 +0.061 · 생활인구 배수 4.3배(추세 **+0.10/년**)
- 평균 체류시간 1,764분(29시간) · 평균 숙박일수 2.70 · 외지인 숙박관심비율 17.3%
- 고령화율 39.7% · 청년비중 12.1% → 정주인구 회복 난망, 체류인구 전략이 유일

**처방(투자 패키지)**
- **워케이션 거점 1개소**: 유휴 공공시설(옛 청사·폐교) 리모델링형 공유오피스 40~50석 + 회의실 (조성비 10~15억)
- **중장기 숙박 15~20실**: 2주·1개월 단위 예약 가능한 숙소를 지역 펜션·게스트하우스와 협약(직영 5실 + 연계)
- **연계 프로그램**: 해양치유센터·완도수목원·청산도 슬로길 + 전복/다시마 로컬 체험 (주말 가족 동반형)

**분기 추적 KPI (베이스라인 → 3년 목표)**
| 지표 | 현재 | 3년 목표 |
|---|---|---|
| 생활인구 배수 | 4.3배 | 4.5~4.7배 |
| 평균 숙박일수 | 2.70 | 2.9+ |
| 숙박자 비율 | 15.8% | 19%+ |
| 2주+ 장기체류 예약 | (신규 집계) | 분기 200건+ |

**기대효과(중심 시나리오)**: 3년 후 추가 체류인구 월평균 +15,900명, 추가 연 관광소비 +54억원

## 2. 충남 부여군 — 우선순위 상위 (75.6), 소비 기반 최대

**진단(데이터)**
- 2×2: 가속 워케이션형 / 궤적: 숙박 전환 진행형 / 체류질: 워케이션형 성장
- 생활인구 배수 4.9배(추세 **+0.13/년**, Tier 1 중 최고 수준) · 성장 모멘텀 +0.048
- 방문자 연인원 1,177만 · **외지인 관광소비 2,107억원/년**(Tier 1 중 최대) · 숙박자 비율 10.0%(낮음)
- → 방문·소비 기반은 크나 **당일 위주**. 체류 전환 여지가 가장 큼

**처방(투자 패키지)**
- **한옥형 워케이션 거점**: 백제문화단지·규암마을 일대 한옥 리모델링 공유오피스 30~40석 (조성비 12~18억)
- **중장기 숙박 20실**: 규암리 근대건축·한옥 스테이 연계, 1개월 살기 상품
- **연계**: 국립부여박물관·궁남지·백마강 + 로컬 식음(연잎밥·표고) 쿠폰

**분기 추적 KPI**
| 지표 | 현재 | 3년 목표 |
|---|---|---|
| 숙박자 비율 | 10.0% | 15%+ |
| 평균 숙박일수 | 2.64 | 2.9+ |
| 생활인구 배수 | 4.9배 | 5.2~5.4배 |
| 외지인 관광소비 | 2,107억 | +8~9% |

**기대효과(중심 시나리오)**: 추가 체류인구 월평균 +20,800명, 추가 연 관광소비 **+190억원**(Tier 1 중 최대)

## 3. 강원 영월군 — 워케이션 지정지(검증), 우선순위 상위 (69.4)

**진단(데이터)**
- 2×2: 가속 워케이션형 / 체류질: 관광수요 성장(추세+·계절변동)
- 생활인구 배수 6.1배(추세 **+0.14/년**, Tier 1 중 최고) · 이미 강원 워케이션 참여 시군
- 평균 숙박일수 2.43(낮음) · 계절 변동계수 큼 → 성수기 쏠림, **비수기 평일 수요가 과제**

**처방(투자 패키지)**
- 기존 강원 워케이션 인프라에 **중장기(2주+) 트랙 추가** + 공유오피스 좌석 20~30석 증설 (조성비 8~12억)
- **비수기·평일 요금 인센티브**: 11~3월 평일 4박↑ 숙박비 50% 지원(강진 반값여행 벤치마크)
- **연계**: 별마로천문대·동강·라디오스타박물관 + 원격근무자 커뮤니티(정기 밋업)

**분기 추적 KPI**
| 지표 | 현재 | 3년 목표 |
|---|---|---|
| 평균 숙박일수 | 2.43 | 2.8+ |
| 생활인구 변동계수(계절 쏠림) | 높음 | 하향 |
| 비수기(11~3월) 숙박 비중 | (집계) | +5%p |
| 생활인구 배수 | 6.1배 | 6.4~6.6배 |

**기대효과(중심 시나리오)**: 추가 체류인구 월평균 +12,800명, 추가 연 관광소비 +73억원

## 공통 — 왜 "패키지"여야 하나

DiD 분석 결과, **워케이션 '지정'만으로는** 체류시간·숙박일수 집계 지표가 움직이지 않았다(p≫0.1).
움직인 곳들의 공통점은 **업무공간 + 중장기 숙박 + 프로그램이 함께** 갖춰진 경우다.
따라서 위 3요소를 묶은 패키지 + 분기 KPI 추적(생활인구 배수·숙박일수)이 실행의 핵심이다.
