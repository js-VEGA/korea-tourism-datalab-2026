## 3-1. `population_89regions.csv` 재생성 — `build_population.py`

### 발견한 문제

기존 파일이 "89/89 성공" 이라 기록돼 있었으나 실제로는 **17개 지역이 사실상 결측**:

- **전남 16개 지역** (강진·고흥·곡성·구례·담양·보성·신안·영광·영암·완도·장성·장흥·진도·함평·해남·화순): KOSIS `DT_1B040A3` 원자료에 **"전남광주통합특별시" 블록**이 있으나 **데이터가 1개월치뿐**(통합 시점 스냅샷). 실제 월별 시계열은 전통 **"전라남도" 블록**(66개월)에 있음. 기존 빌더가 이름만 보고 통합특별시 블록에 매칭 → 1개월치만 들어옴.
- **대구 군위군**: 2023.07 대구 편입. 경상북도 블록(2021.01~2023.06) + 대구광역시 블록(2023.07~2026.07) 로 분리 저장돼 있음.

### 해결

`build_population.py` (KOSIS 원자료 `~/Downloads/101_DT_1B040A3_*.csv` 직접 파싱):
- 시도 마커 행으로 블록 경계를 잡고, 블록 안에서 시군구명 정확 일치로 매칭
- 광역명 매핑: `전남광주통합특별시 → 전라남도` 블록 사용
- 군위군: 경북 블록(과거) + 대구 블록(최근) **이어붙이기** (겹치면 대구값). 202306→202307 연속성 확인 (23186 → 23165, 이상 없음)

### 결과

- 89/89 지역, 총 5947행
- 73개 지역: 202101~202607 (67개월) / 전남 16개: 202101~202606 (66개월, 202607 미공표)
- 패널 구간(202201~202606) **총인구수 결측 0**
- 기존 파일은 `population_89regions.csv.bak` 로 백업

## 3-2. `build_master_table.py` (pandas)

### 조인

| 소스 | 키 | 방식 |
|---|---|---|
| tourism_panel | (base) | 지역-월 |
| regions.csv | 지역명_full → SGG_CD | 지역코드 부여 |
| population_89regions | 지역명_full + 기준연월 | left |
| national_benchmark | 기준연월 | left (전국평균 broadcast) |
| region_static_features | **광역지자체명 + 지역명** | left (동명이지역 고성군·서구 때문에 광역까지 키로) |
| quadrant_snapshots | SGG_CD + period_bucket | left (3기간 스냅샷을 해당 월에 부여) |
| recent_visitor_composition | (지역명) | **파일 없음 → 생략, 있으면 자동 병합되게 훅만** |

초기 실행에서 stat 을 `지역명` 만으로 조인해 고성군·서구가 2배로 불어난 버그(5022행) → 광역+지역 키로 수정, 4806행 정상.

### 파생 피처 (지역별 시간정렬 후 groupby)

- **인구**: 인구_로그, 인구_전월비, 인구_yoy, 인구감소율_12개월(= −yoy)
- **타깃 y = 방문자수_연인원**:
  - y_log, y_lag_{1,3,6,12}, y_yoy
  - y_rollmean_{3,6,12}, y_rollstd_6, y_trend_6 (= rollmean3/rollmean6 − 1) — 전부 `shift(1)` 적용 (누수 방지)
  - **예측 타깃**: y_lead_{1..6}, glog_{1..6} (= ln y_lead_k − ln y), y_lead_mean_1_6, glog_mean_1_6
- **계절**: 월_sin, 월_cos
- **체류/숙박 전국대비**: 체류시간_전국대비차, 숙박자비율_전국대비차, 평균숙박일수_roll6, 체류시간_roll6
- **관광소비** (내국인 = 외지인 + 현지인 실측 확인): 외지인소비_비중, 1인당_외지인관광소비_천원, 1인당_관광소비_천원, 관광소비_외지인_yoy, 지역화폐_소비_비중
- **검색**: 내비검색_yoy

### 검증

- shape 4806 × 113, 89지역 × 202201~202606
- 정합성: `y_lag_1[t]==y[t-1]`, `y_lead_1[t]==y[t+1]`, `y_rollmean_3` = 직전 3개월 평균 — 전부 통과 (누수 없음)
- 총인구수·y·분기_평균체류시간·체류시간_전국대비차·외지인소비_비중 결측 0
- **학습 가용 표본**: y_lag_12 & y_lead_6 & y 모두 존재 = **3204행** (202301~202512)
