# 17. 기대효과 규모 추정 (단계 12-1)

- **기간**: 2026-09-02
- **상태**: ✅ 완료 (→ 가정 부분은 devlog 19 에서 교정됨)
- **한줄요약**: Tier 1 13곳에 워케이션 거점(≈15억/곳) 조성 시, 생활인구 배수가 3년간
  +0.2~0.35 상승한다는 **시나리오 가정** 하에 3년차 추가 연 관광소비
  **+829억~1,450억원**, 추가 체류인구(월평균) **+15.6만~27.4만명** 으로 추정.

---

## 왜 만들었나

Tier 분류까지만으로는 "그래서 이걸 하면 얼마나 되는데?"에 답할 수 없다.
투자 우선순위를 제안하는 이상 **투자 규모 대비 회수 규모의 감**이 없으면 의사결정 자료가 못 된다.
단, 관측된 인과가 아니므로 **"예측"이 아니라 "가정 기반 시나리오"** 임을 명시한다.

## 논리 사슬 (`17_impact_projection.py`)

```
워케이션 거점 조성(공유오피스+중장기숙박)
  → 생활인구 배수가 3년간 총 +UPLIFT 추가 상승 [가정]
  → Δ체류인구 = 주민등록인구(근사) × Δ배수
  → Δ관광소비 = Δ체류인구 × 1인당 연 관광소비
                (= 지역 외지인 관광소비 최근12M ÷ 평균 체류인구)
```

## 가정

| 항목 | 값 | 근거 |
|---|---|---|
| 효과 관찰기간 | 3년 | — |
| 거점 조성비 | 지역당 15억 (10~20억) | 공공 워케이션센터 리모델/신축 실적 개략 |
| 배수 상승폭(3년) | 보수 +0.20 / 중심 +0.35 | 현 Tier 1 상위(영월 +0.14·해남 +0.16·부여 +0.12 /년)의 3년 상승폭(+0.37~0.48) |
| 한계인 소비강도 | 평균 체류인구와 동일 | 관측된 (외지인소비÷체류인구) 비율 그대로 적용 |
| 대조 근거 | 지정만으로는 효과 없음(DiD, devlog 16) | 인프라가 추세를 바꿔야 한다는 전제 |

> **▶ 변경 (2026-09-09)** — 위 '배수 상승폭' 근거는 **체리피킹이었다**. Tier 1 13곳의 자력 추세를
> 전수 확인하면 3년 환산 **-0.86 ~ +0.48, 중앙값 +0.10** 이며, +0.37~0.48 구간에 드는 것은 13곳 중
> 2곳뿐이다. 따라서 +0.20/+0.35 는 "보수적"이 아니라 **상위권 수준의 가정**이다.
> → 최종본에서는 **최소 시나리오(+0.10, 중앙값)를 하한으로 추가**하고 가정의 실제 분위를 명시했다.
> 상세: devlog 19 §1.

## 한계

- 체류인구는 월평균 stock → 한계 체류인구가 연중 내내 체류한다고 가정하면 상단 추정.
- 배수 상승이 **인프라 때문**이라는 인과는 미검증(시나리오). 지정 효과 DiD 는 null 이었음.
- 거점 조성비는 개략치. 실제는 규모·부지에 따라 편차 큼.
