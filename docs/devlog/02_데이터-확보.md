## 2-2. 데이터랩 대시보드 (Selenium 자동 다운로드)

- 89개 지역 × 3개 탭(방문자 / 숙박·체류시간 / 관광소비) × 3개 기간(2022.01~2023.06 / 2023.07~2024.12 / 2025.01~2026.06) 순회
- 18개월 조회제한 때문에 기간 3분할
- URL `?SGG_CD=코드` 로 지역 이동, `#monthStart`/`#monthEnd` 는 **YYYYMM(하이픈 없음)**, 다운로드 버튼 `#download`
- 결과: `datalab_raw/지역명__탭명__기간.zip`
- **상태**: 미완 — 상세 이력은 [03](03_데이터랩-다운로드-파이프라인.md)

### 탭별 파일 구조 (실제 다운로드해서 확인 완료)

**방문자 탭**
- `방문자_수_연인원_추이` — 월별 절대값 시계열 (**핵심 예측 타깃**)
- 내비 검색 현지인·외지인 관심지점 비교 / 외국인 방문 현황 / 거리별 방문자 분포 / 내비 검색 유형 분포 / 내비 목적지 유형별 검색량(월별) / 방문자 거주지 분포(구조 미검토) / 방문자 성연령별 분포

**숙박·체류시간 탭**
- `순 방문자 수 및 숙박 비율`(월별), `평균 숙박일`(월별), `숙박 목적지 검색건수`(월별), `숙박 유형별 방문자 비율`(월별)
- `방문자 체류특성` — **사분면용**. 대상 지역 소속 광역 내 전체 시군구가 같이 나옴 → 지역코드 기준 dedupe
- `숙박방문자 비율 추이`, `평균 체류시간 추이` — 전국평균 행이 섞여 있음
- `숙박 목적지 유입 지역 분포` — 광역별 100% 정규화 블록 15개. 전체 합산 무의미 → **"동일광역 내 집중도"로 재정의** (동일광역_최대유입기초 / 상위3비율합 / HHI)

**관광소비 탭**
- `관광소비_추이` 내국인/외지인/현지인(월별), `전국_대비_관광소비_추이`(월별 %), `지역화폐_관광소비_추이`(월별)
- `관광소비` 내국인/외국인 업종별 스냅샷, `성연령별_내국인_관광소비_분포` 스냅샷

## 2-4. TourAPI (공공데이터포털)

- 엔드포인트: `apis.data.go.kr/B551011/DataLabService/locgoRegnVisitrDDList` — 기초지자체 **일별** 방문자수, 현지인/외지인/외국인 구분 (데이터랩 대시보드에 없는 정보)
- 인증: 서비스키는 로컬 환경변수 `TOUR_API_KEY` (코드 하드코딩 금지). 개발계정 일 1,000건 제한
- `test_tourapi.py` — 인증 테스트 + 89개 필터링 + 결측 진단
- `fetch_recent_snapshot.py` — 최근 1개월(2026.06) 현지인/외지인/외국인 비중 스냅샷 → `recent_visitor_composition.csv` (지역당 1행, 정적 피처)
- **전략**: 데이터랩에서 월별 시계열을 이미 확보 → 이 API는 전체기간 재수집(옵션 C)이 아니라 **"외지인/외국인 비중" 신규 피처 1건만** (옵션 A, 최근 스냅샷)
- **상태**: `fetch_recent_snapshot.py` 결과 파일 아직 없음 → 미실행. 재실행 필요
