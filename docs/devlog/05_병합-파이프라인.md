## 2a. 월별 시계열 병합 — `process_datalab.py`

`process_sukbak.py`(숙박탭, 정합성 검증 완료)의 로직을 그대로 포함하고 방문자·관광소비 탭 월별 시계열을 추가한 통합 스크립트. **표준 라이브러리만.**

### zip 내부 구조 (실측)

- 모든 기간 파일이 정확히 **18개월**. 3개 파일 이어붙이면 **2022.01~2026.06 연속 54개월**, 결측 구간 없음.
- **방문자 탭 월별**: `방문자수(연인원)추이`(방문자수·전년동월·증감률), `내비게이션목적지유형별검색량` '전체' 행(월별 검색량)
- **관광소비 탭 월별**: `관광소비추이_내국인/외지인/현지인` '전체' 행(소비액 천원), `전국대비관광소비추이_*`(전국 대비 비율 + 전국 총액), `지역화폐관광소비추이`(소비금액 천원)
- 날짜 컬럼명이 파일마다 `기준연월` / `기준년월` 혼용 → 둘 다 처리
- 소비액이 지수표기(`1.4532674E7`) 로 저장됨 → `float()` 로 정상 파싱

### 검증 결과

- 지역수 89/89, 모든 지역이 정확히 54개월 (이상치 0)
- **정합성**: 숙박자 비율 ↔ 숙박방문자비율_추이 **4788행 완전일치** (불일치 0)
- 전국평균 값 불일치 0건, 지역명 매칭 실패 0건
- 채움률: 숙박·방문자·소비 지표 대부분 4788/4806 (99.6%). 빈 18행 = 재수집 필요분(아래)
- `지역화폐_소비액_천원`: **1468/4806 (31%)** — 지역화폐 데이터는 2025년~ 최근 구간에만 제공(84개 지역, 대부분 18개월). 5개 소규모 구(청송군·대구 남구/서구·부산 동구/영도구)는 전무. → 모델링 시 최근 구간 한정 피처로만 사용하거나 제외.

### 알려진 결측 (systematic)

`방문자성연령별분포` · `외국인방문현황` 이 **전남광주통합특별시 16개 지역 전부**에서 3개 기간 통틀어 부재
(강진·고흥·곡성·구례·담양·보성·신안·영광·영암·완도·장성·장흥·진도·함평·해남·화순).
→ 이 6개 컬럼은 18% 결측이 한 광역에 몰려 있음. 모델 피처로 쓰면 "전남 여부" 대리변수가 될 위험
→ 단계 5(피처선택)에서 제외 또는 광역더미와 함께만 사용 결정. 나머지 18개 컬럼은 89/89.
