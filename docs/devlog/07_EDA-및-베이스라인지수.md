## 단계 4. EDA — `04_eda.py`

출력: `outputs/figures/eda_01~04.png`, `outputs/tables/eda_summary.txt`

### 관측

1. **체류시간×숙박일수 사분면 (최근 분기)**: 중앙값 체류시간 1126분 / 숙박일수 2.64일.
   우상단(둘 다 중앙값 이상) **30개 지역** — 강원 산간(양구·철원·태백·화천), 경북 내륙(봉화·상주·안동·영양·영주·의성·울진), 전남 도서(강진·고흥·신안·영광·영암·완도·장흥·진도·해남), 전북(남원·장수·정읍), 충청(논산·부여·청양·영동).
   울릉군은 체류시간 4510분(75시간) 극단 이상치 — 섬 접근성 때문에 강제 장기체류.
2. **사분면 이동 (2022상→2025~26상)**: 체류시간 중앙값이 **전반적으로 하락**(1342→1171→1126분, 포스트코로나 정상화). 이 하락 추세를 **역행해 체류시간·숙박일수 둘 다 상승한 지역은 4곳뿐** — 논산시(+142분), 강화군(+74), 신안군(+61), 연천군(+15). → "진짜 체류형 전환" 신호로 해석.
3. **방문자 계절성**: 10월(119)·8월(118)·5월(112) 성수기, 2월(82)·12월(83) 비수기.
4. **예측타깃(다음 6개월 로그성장 glog_mean_1_6)과 상관**: 대부분 약함.
   - y_trend_6 **−0.44** (평균회귀: 최근 급성장 → 향후 둔화)
   - 1인당 외지인관광소비 −0.28, y_yoy −0.22, 내비검색 yoy −0.21
   - 체류시간 **+0.20**, 평균숙박일수 +0.19, 체류시간 전국대비차 +0.17 (체류형일수록 향후 성장 약간 높음 — 가설 지지하나 약함)
   → **6개월 방문자 예측은 난이도 높음.** 정적 체류 피처의 월별 예측력은 제한적. 모델(단계 6)이 비선형·상호작용을 잡아야 함.

## 단계 5. 베이스라인 지수 v0 — `05_baseline_index.py`

지역당 1행 스냅샷(`wcation_snapshot.csv`) → 11개 컴포넌트 z-score(±3 클립) → 그룹 평균 → 가중합.

| 그룹 | 가중 | 컴포넌트 |
|---|---|---|
| A 체류 구조 | 0.45 | 평균체류시간, 평균숙박일수, 숙박자비율(최근12M), 체류시간 전국대비차, 체류시간 추세 |
| B 수요 성장 | 0.30 | 방문자수·외지인관광소비·내비검색량 성장률 (최근12M vs 직전12M) |
| C 관광 목적성 | 0.25 | 외지인소비 비중, 190km+ 방문 비중, 외지인 숙박관심비율 |

인구감소 심각도는 지수에 넣지 않고 별도 축(정책 우선순위 프레임에서 결합).

### 결과 (지수_가중합_100)

- **상위 10**: 남해군(100) · 완도군(85.5) · 청양군(84.7) · 영월군(81.6) · 양구군(75.1) · 고성군[강원](73.9) · 부여군(73.5) · 영양군(73.2) · 진도군(72.0) · 신안군(70.5)
- **하위**: 군위군(0) · 함양군(9.6) · 담양군(14.4) · 가평군(15.4) · 무주군(16.1)
- 스냅샷 검증: 남해=체류시간1409·숙박자비율24%·소비성장+21% (전그룹 강세), 가평=근거리 당일치기형·성장정체 (하위 타당), 함양=2024년 급성장 후 최근 정체 (EDA의 +25%는 이전 창 기준)

### 한계 / 캐비앳 (v1·모델에서 개선)

1. **지수가 가중치에 민감**: 가중합 vs PCA1 순위 스피어만 상관 **0.22**, PCA1 설명분산비 0.34. → 단일 "워케이션 잠재력" 잠재요인이 없음. 11개 신호가 서로 독립적. → **단계 6~7에서 예측력 기반으로 가중을 데이터가 정하게 함** (지수 v1).
2. **남해군 인구 이상치**: 2025.10~12 총인구 +약1,700 급증(39.4k→41.1k), KOSIS 원자료 그대로. 원인 미상(연수원/외국인등록/귀촌 정책 추정). 지수 순위엔 영향 없으나(관광성장 기반) 정책 프레임에선 "인구 회복"으로 잡힘 — 서식4 작성 시 별도 확인 필요.
3. **정책 우선순위 사분면이 24개로 느슨**: 중앙값×중앙값 교차라 넓음. v1/정책매칭에서 상위 tercile 등으로 조일 것.
