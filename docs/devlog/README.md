## 이 기록에서 봐주셨으면 하는 것

가설을 세우고 **데이터로 기각한 지점**이 세 번 있습니다.

1. **단일 지수로 순위화** (07) → 가중치를 어떻게 두느냐에 순위가 뒤집힘(가중합 vs PCA ρ=0.22) → 지수 폐기
2. **성장률 예측으로 순위화** (08) → 시간분할 R² 0 수준 → 모델 역할을 '동인 규명 + 상대 랭킹'으로 한정
3. **생활인구 배수 '수준' 사용** (13) → 우선순위와 음의 상관(계절 관광지가 최상위) → '추세'만 채택

그리고 마지막에 **자기 결과를 다시 의심한 기록**(19)이 있습니다.
직교성 상관계수의 부호가 틀렸고, 회고 검증을 유의하지 않은 채로 유의한 것처럼 썼으며,
기대효과 가정의 근거가 체리피킹이었습니다. 전부 교정하고 그 과정을 남겼습니다.
