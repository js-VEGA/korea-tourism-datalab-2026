### 1-1. 회고 검증 재프레이밍

기존 "예지력" 주장은 상위 컷오프를 어디로 두느냐에 민감했고 유의하지 않았다.
컷을 바꿔가며 유의해지는 지점을 찾는 것은 p-해킹이므로, 대신 **컷오프가 필요 없는 검정**으로 옮겼다.

| 검정 | 결과 |
|---|---|
| 신규지정 11곳 · 상위 30 컷 (기존) | lift 1.35배, **p = 0.289** — 비유의 |
| 신규지정 11곳 · 상위 20 컷 | lift 2.02배, p = 0.065 — 컷 고르기 = p-해킹 위험 |
| **지정·운영 27곳 전체 · Mann-Whitney 연속형** | **단측 p = 0.046** — 유의 |

→ 주력 주장을 "예지력(미래 지정 맞히기)"에서 **"구성 타당도(이미 지정된 곳에서 지표가 실제로 높은가)"**
로 교체하고, 예지력의 비유의성(p = 0.29)은 **한계로 명시**했다. 표본 11곳으로는 검정력이 부족하다.

### 1-2. 외부 사례 검증 — 강진군

모델이 사전 정보 없이 산출한 Tier 1(89곳 중 13곳) 안에 **강진군**이 들어있는지 확인한 적이 없었다.
확인 결과: 사분면 "가속 워케이션형", **Tier 1(즉시 투자)** 로 분류. 강진군의 관광 정책 성과 정보는
모델 입력에 일절 포함되지 않았다. 독립 사례에 대한 외부 검증으로 서식4·그림·대시보드에 반영.

## 2. 시각화 전면 재제작

### 진단 — 기존 그림의 공통 결함

1. `tab10`·`YlOrRd` 등 라이브러리 기본 팔레트 (`YlOrRd` 는 흑백 인쇄 시 판독 불가)
2. **색-의미 매핑이 그림마다 다름** — `cluster_03` 은 가속워케이션형=파랑, `living_02` 는 같은 유형이 빨강
3. 89개 라벨을 전부 찍어 중앙부 판독 불가
4. **아웃라이어 미처리** — 울릉군 성숙도 1.74 vs 차순위 ~1.0 로 축의 상당 부분이 빈 공간
5. `cluster_03` **부제 오류** — "우하=떠오르는 잠재지"로 적혀 있으나 코드상 좌상단 (→ 코드 수정)
6. `shap_01` 피처명이 날것(`y_rollmean_12`, `월_cos`) + |SHAP| 이라 촉진/억제 방향성 소실
7. `backtest_01` 우측 패널이 하위 1.5% > 상위 1.3% 로 **자기 주장을 반박**

### 렌더 검증에서 잡은 결함 2건

- **한글에 영문용 자간 적용** — 라벨이 "체 류 의 질"처럼 벌어짐. `letter-spacing .1~.14em` → `.02em`,

  요소라 이후 마크업 전체가 CSS 텍스트로 흡수되어 **콘솔 오류 없이 백지**가 된다.
