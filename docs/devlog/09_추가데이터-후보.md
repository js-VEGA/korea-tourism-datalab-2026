## 왜 필요한가

현재 피처는 데이터랩(관광 행태) + KOSIS 총인구 + 데이터랩 정적 스냅샷뿐.
"워케이션 잠재력" 을 더 직접 측정하려면 **① 체류 인구 실측 ② 워케이션 인프라 ③ 인구 구조(청년/고령)** 가 빈다.

## Tier 1 — 가치 높음 + 획득 쉬움 (착수 권장)

### 1. 생활인구 (통계청 국가데이터처) ★최우선

- **무엇**: 등록인구(주민+등록외국인) + **체류인구**(월 1회·하루 3시간+ 체류). 89개 **인구감소지역 전체**, **분기별**, 연령별.
- **왜**: 체류인구/등록인구 배수 = 워케이션 잠재력의 준-직접 지표. 2024Q1 기준 인구감소지역 생활인구가 등록인구의 약 4배라는 보도 있음. 우리 지수/모델의 타깃 또는 강력한 피처가 될 수 있음.
- **출처**: `data.kostat.go.kr/nowcast/popul_living_age.do` (시군구별 생활인구:연령별). 분기별 공표.
- **획득**: 웹 조회+다운로드 또는 API. 페이지 구조 확인 후 파이썬 자동화 가능.
- **주의**: 시범산정 2023 → 89개 확대 2024~. 시계열이 짧음(분기 ~8개 내외). 월별 데이터랩과 주기 다름(분기 → 보간 or 분기 패널 별도).

### 2. 연령대별 주민등록인구 (KOSIS)

- **무엇**: 시군구 × 월(또는 연) × 5세 단위 인구. 현재 `population_89regions.csv` 는 총/남/여만.
- **왜**: 청년(20~39) 비중, 고령화율(65+), 생산가능인구 비중 → 워케이션 수요·수용 여건.
- **출처**: KOSIS 주민등록인구현황 연령별 표 (DT_1B04005N 등). 이미 받은 `DT_1B040A3` 와 같은 포털.
- **획득**: KOSIS에서 표 하나 더 다운로드. `build_population.py` 블록추적 로직 재사용.

### 3. 공유오피스 / 코워킹스페이스 시설 (공공데이터포털)

- **무엇**: 전국 공유오피스·비즈니스센터·코워킹 시설 위치 목록 → 시군구별 개수 집계.
- **왜**: 워케이션 인프라의 핵심 필요조건. 지역별 공급을 직접 측정.
- **출처**:
  - 한국문화정보원_전국 공유 오피스 시설 데이터 (`data.go.kr/data/15111411`, 파일, 무로그인) — 2022.11
  - 중소벤처기업진흥공단_공유오피스 운영 현황 (`data.go.kr/data/15108094`) — 2024.08
- **획득**: 파일 다운로드 → 주소/좌표를 시군구로 매핑.
- **주의**: 기준시점 2022~2024. 인구감소지역엔 시설이 희소(0~few)할 가능성 → "유무" 이진 + 인접 도시 접근성으로 보완.

## Tier 2 — 가치 있음, 획득 중간

### 4. 워케이션 지원사업 지정 지자체 목록 (한국관광공사 / 대한민국 구석구석)

- **왜**: 정부가 이미 선정한 지역 = **검증 라벨**(모델·지수가 이들을 상위로 뽑는지) + 단계 9 정책매칭 입력.
- **현재까지 확인**: 남해·함양(경남), 속초, 부산 해운대, 제주, 충남 등. 전체 목록은 흩어져 있음.
- **출처**: 대한민국 구석구석 '워케이션' 페이지, 한국관광공사 보도자료, KBIZ 공고. 연도별(2023~2025) 선정 현황 수집 필요.
- **획득**: 웹 스크래핑 + 수기 정리.

### 5. 데이터랩 미수집 탭 (기존 스크래퍼 재사용)

- **소셜미디어**: 지역별 언급량(버즈) 시계열 → 관심도 선행지표.
- **인기관광지**: 관광지별 방문 집중도 → 매력 자원 분포.
- **획득**: `download_datalab.py` 의 TABS 리스트에 추가만 하면 됨. 로그인 세션 필요(v3).

### 6. 관광 수용력 — 숙박시설/객실 수

- **왜**: 체류형 관광의 물리적 상한. 워케이션 수용 가능 규모.
- **출처**: 한국관광 관광지식정보시스템(관광사업체 현황), TourAPI 숙박 분류 카운트.

### 7. 청년 순이동인구 (KOSIS 국내인구이동)

- **왜**: 20~40대 전입−전출 = 지역 활력·정주 매력. 워케이션→정착 파이프라인.
- **출처**: KOSIS 국내인구이동통계, 시군구 × 연령 × 전입/전출.

## 권고

1. **먼저**: Tier 1 세 개(생활인구 / 연령별 인구 / 공유오피스) → 페이지 구조 확인 후 파이썬 자동 수집.
   - 특히 **생활인구**는 이 프로젝트 주제와 정확히 겹침(인구감소지역 × 체류). 최우선.
2. **그 다음**: Tier 2 의 워케이션 지정지 목록(검증용) + 데이터랩 소셜미디어 탭.
3. Tier 3 는 서식4 서술 보강용으로 필요 시.

수집 착수 여부는 사용자 확인 후. 그 전까지 단계 7~9 는 현재 데이터로 진행하고, 추가되면 마스터 테이블에 재조인.
