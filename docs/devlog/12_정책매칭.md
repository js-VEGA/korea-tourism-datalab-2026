## 투자 우선순위 점수 (`policy_priority.csv`)

`우선순위_raw = 1.0·z(성장모멘텀) + 0.7·z(장기 인구감소율) + 0.5·z(v1c) + 0.3·z(외지인 숙박관심)`
→ 0~100 정규화. **인구감소 심각도는 12개월 yoy(노이즈·남해 이상치) 대신 2021.01→2026.06 장기 누적감소율** 사용.

| Tier | 정의 | n | 권고 액션 |
|---|---|---|---|
| **Tier 1 (즉시 투자)** | 가속 워케이션형 ∩ 인구감소 심각 | 13 | 공유오피스·중장기숙박 등 **체류 인프라 직접 투자** → 방문→체류 전환. 외지인 숙박관심 높은 곳 우선(SHAP) |

## 프레임 정합성 점검 (확인된 워케이션 지정지 6곳, 부분·미검증)

| 지역 | 우리 사분면 | Tier |
|---|---|---|
| 강원 영월 | 가속 워케이션형 | **Tier 1** ✓ |
| 경남 함양 | 떠오르는 잠재지 | **Tier 2** ✓ (성장 모멘텀 1위) |
| 전북 진안 | 떠오르는 잠재지 | Tier 2 ✓ |
| 경남 남해 | 성숙·정체 | Tier 3 |
| 강원 고성 | 성숙·정체 | Tier 3 |
| 경남 하동 | 저잠재 | 관찰 ← 약점 |

**해석**: 3/6은 상위 Tier로 정합. 남해·고성은 "이미 체류형인데 예측 성장 모멘텀 낮음" → SHAP의 "체류 성숙 → 성장 여력 소진"과 일치(둘 다 유지·관리 대상으로 분류하는 게 합리적). **하동(저잠재)은 명확한 약점** — 현재 피처로는 하동의 잠재를 못 잡음 → 생활인구·인프라 데이터(devlog 09) 추가 필요 근거.

**프레임의 가치**: 정부 기존 선정지를 그대로 재현하는 게 아니라, **완도·울진·고흥·안동·영주 등 아직 미지정이지만 데이터상 우선순위 높은 신규 후보**를 제시. + KTO 워케이션 참여 지자체의 **70%+가 인구감소지역**이라는 사실은 주제 정당성 근거.
