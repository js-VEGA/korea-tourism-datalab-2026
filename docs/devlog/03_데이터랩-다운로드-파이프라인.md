## 타임라인

### 08-30 (이전 세션) — v1 작성 및 1차 수집

- `download_datalab.py` v1: 89 지역 × 3 탭 × 3 기간 순회, 지역 이동 → 날짜 설정 → 탭 클릭 → `#download` 클릭 → zip 을 `datalab_raw/지역명__탭명__기간.zip` 으로 이동

### 08-31 (현재 세션) — 실측: 3개 탭 모두 미완

- 추가로 **깨진 `.tmp` 38개** 발견
- `_log.csv` 상태 집계: OK 325 / NO_NEW_FILE 74 / TAB_CLICK_FAIL 40
- 누락 목록 → `datalab_raw/_missing_manifest.csv` (420건)

**원인 분석 (v1 버그)**

1. **탭 클릭 인터셉트 (TAB_CLICK_FAIL 40)** — `element click intercepted: ... <div id="loading"> would receive the click`. 로딩 오버레이(`#loading`/`#loadingSpin`)가 떠 있는 동안 탭을 클릭. `EC.element_to_be_clickable` 로는 오버레이 유무를 못 거름.
2. **임시파일 오판 (`.tmp` 38개)** — 이 사이트는 다운로드 진행 중 파일이 `.crdownload` 가 아니라 `.tmp` 로 나타나는 경우가 있음. v1은 `.crdownload` 만 걸러서 아직 안 받아진 `.tmp` 를 "완료"로 보고 이동.
3. **로그 유실 위험** — 로그를 `finally` 에서 한 번에 씀. 강제 종료/정전 시 손실.

### 08-31 — v2: 앞 3개 버그 수정

- `wait_loading_gone()` — `#loading` 등이 사라질 때까지 대기 후 클릭
- `click_tab()` 최대 4회 재시도 + intercept 시 JS 클릭 폴백
- `click_download_and_wait()` — 최종 `.zip` 이 나타나고 **크기가 2회 연속 동일**할 때까지 대기. `.tmp`/`.crdownload` 는 진행중으로 간주
- 지역마다 `_log.csv` **append** (즉시 기록)
- 실행 중 `SetThreadExecutionState` 로 절전/화면꺼짐 억제
- 시작 시 잔여 `.tmp`/`.crdownload` 청소
- 깨진 `.tmp` 38개 삭제 완료

**부수 작업**: Python 3.14 에 `pandas 3.0.5 / numpy 2.5.2 / scikit-learn 1.9.0 / lightgbm 4.7.0 / shap 0.52.0` 설치 성공 (대체 라이브러리 불필요 확인)

### 08-31 — v2 실행 → 로그인 세션 만료 발견

사용자가 v2 실행. 초반 ~60건 받다가 이후 거의 전건 실패. 로그 alert 텍스트(cp949 복원):

- `로그인 후 이용이 가능합니다.` ← 핵심
- `오류가 발생하였습니다. 관리자에게 문의 하세요.` + `TypeError: Failed to execute 'createObjectURL'`
- `DATE_SET_FAIL` 다수 (빈 메시지 + chromedriver 스택트레이스 = 방치된 alert 이 이후 호출을 연쇄 크래시)

**해석**: 데이터랩 "전체 다운로드" 는 로그인 세션 필요. Selenium 크롬은 별도 프로필이라 비로그인. 기존 ~440개는 세션 살아있던 구간에 받아진 것. 중간에 세션이 풀리면서 이후 전건이 "로그인 필요"로 실패. 방치된 alert 이 `set_date_range` 의 후속 호출들을 연쇄 실패시킴.

이 시점 확보: **443 zip**. 9/9 완전 지역 19/89, 관광소비 최근구간 제외 8/8 지역 35/89.

### 08-31 — v3: 로그인 세션 대응

- `MANUAL_LOGIN` — 시작 시 크롬을 데이터랩 메인으로 띄우고 **사용자가 직접 로그인** → 콘솔 Enter → 그 세션으로 진행
- `drain_alerts()` — 모든 상호작용 전에 밀린 alert 을 전부 accept. 로그인 alert 섞이면 `NeedLoginError`
- `NeedLoginError` 처리 — 해당 지점에서 멈추고 재로그인 요청(`pause_for_relogin`) 후 그 지역부터 재시도
- `SLEEP_BETWEEN_REQUESTS` 2→3초 (봇 감지 완화 목적)
- resume 유지 → 기존 443개는 자동 skip

## 얻은 교훈

- 데이터랩 전체 다운로드는 **로그인 세션 의존**. 무인 수집이면 세션 쿠키 주입 또는 수동 로그인 스텝 필수
- Selenium 다운로드 완료 판정은 확장자 화이트리스트(`.zip` 등장 + 크기 안정)로. 블랙리스트(`.crdownload` 제외)는 사이트마다 샘
- 방치된 alert 하나가 이후 모든 WebDriver 호출을 깨뜨림 → 매 스텝 앞에서 alert 배수 필요
