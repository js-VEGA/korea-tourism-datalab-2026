# 10. SHAP 해석 & 워케이션 지수 v1 (단계 7)

- **기간**: 2026-09-02
- **상태**: ✅ 완료 — 핵심 발견: **"이미 체류형인 곳"과 "앞으로 성장할 곳"은 거의 무관**(v0 vs 모델예측 스피어만 0.16) → 단일 지수보다 **2축 프레임**이 맞다.
- **한줄요약**: 회귀기법 5종+앙상블 비교(LightGBM 최고, R²0.12) → SHAP/gain/permutation 삼각검증(순위상관 0.82~0.85, 일관) → 지수 v1 3방식 산출·비교.

## (A) 회귀기법 비교 — g12, 지역 GroupKFold (`model_bakeoff.csv`)

| 모델 | MAE | 상관 | R² | 방향정확도 |
|---|---|---|---|---|
| **LightGBM** | **0.0313** | **0.368** | **0.122** | 0.688 |
| ExtraTrees | 0.0317 | 0.303 | 0.085 | 0.640 |
| ElasticNet | 0.0341 | 0.227 | 0.050 | 0.610 |
| 앙상블(LGB+RF+HistGBR) | 0.0326 | 0.293 | 0.043 | 0.670 |
| HistGBR | 0.0346 | 0.288 | −0.022 | 0.675 |
| RandomForest | 0.0345 | 0.159 | −0.121 | 0.641 |

→ LightGBM 단독이 최고. 앙상블·RF는 오히려 악화. 이후 SHAP은 LightGBM(숫자 피처만, 범주형은 SHAP 호환 이슈로 제외) 기준.

## (B) SHAP 해석 (`shap_01~03.png`)

평균 |SHAP| 상위 + beeswarm 방향성:

| 피처 | 방향 | 해석 |
|---|---|---|
| 숙박방문자비율_전국평균 / 체류시간분_전국평균 | 값 낮을수록 +g12 | **시간(계절) 대리변수** — 전국 공통값. 모델이 계절 위치를 사용 (지역 랭킹 정보 아님) |
| **외지인_숙박관심비율** | 높을수록 **+** | 외지인의 숙박 관심 큰 지역 → 성장 ↑. 진짜 워케이션 신호 |
| 분기_평균체류시간 / 체류시간_roll6 | **높을수록 −** | **이미 체류시간 긴 지역은 향후 성장 여력 작음(평균회귀)** — "체류 성숙 ≠ 성장" |
| 거주_광역HHI | 낮을수록 **+**(큰 양의 이상치) | 방문객 출신지가 다양할수록 성장 ↑ |
| 지역화폐_소비_비중 / 액 | 높을수록 **+** | 지역화폐 활성 = 정책 관여·소비 유입 프록시 |
| 인구감소율_12개월 | 높을수록 소폭 **−** | 인구 급감 지역은 방문자 성장도 약간 낮음 |
| 방문자수_증감률 / y_yoy | 혼재 | 최근 모멘텀 (부분적으로 평균회귀) |

**핵심**: 성장 동인 = 외지인 숙박관심 + 방문객 출신 다양성 + 지역화폐 활성. 억제 = 이미 높은 체류시간(여력 소진) + 인구 급감.

## (C) 중요도 삼각검증 (`importance_triangulation.csv`)

gain / SHAP / permutation 순위 스피어만 상관 **0.82~0.85** — 세 방법이 일관. 상위 피처 결론 견고.

## (D) 워케이션 잠재력 지수 v1 (`wcation_index_v1.csv`)

3가지 방식으로 산출하고 v0(z가중합)와 비교:

| 방식 | 정의 |
|---|---|
| v1a | 모델의 지역별 예측 성장성향 pred_g12 (원점 202506) 만 |
| v1b | SHAP 상위 구조 동인 8개를 mean\|SHAP\| 로 가중한 z-합 |
| v1c | v0 체류구조 소계(za) + 예측성장(zg) 50:50 블렌드 |

### 버전 간 스피어만 상관

| | v0 | v1a | v1b | v1c |
|---|---|---|---|---|
| v0 | 1.00 | **0.16** | 0.46 | 0.54 |
| v1a | 0.16 | 1.00 | **−0.00** | 0.64 |
| v1b | 0.46 | −0.00 | 1.00 | 0.55 |
| v1c | 0.54 | 0.64 | 0.55 | 1.00 |

Top-10 겹침: v0∩v1a = **1개**, v0∩v1b = 5, v0∩v1c = 3.

### 결론: 단일 지수 대신 2축

**v0(체류 성숙도)와 v1a(성장 모멘텀)는 거의 직교(상관 0.16, top10 겹침 1).**
→ "이미 체류형인 곳"과 "앞으로 뜰 곳"은 다른 집합. 하나의 점수로 뭉개면 정보 손실.
→ **2축 프레임**으로 간다 (단계 8 유형화에서 구체화):
- **축 1 — 체류 성숙도**: 이미 체류형 관광이 자리잡았나 (v0 소계_A / 사분면 우상단)
- **축 2 — 성장 모멘텀**: 향후 12개월 방문자 성장성향 (모델 pred_g12)
- 2×2: `이미 워케이션형` / `떠오르는 잠재지` / `성숙하나 정체` / `저잠재`
- v1c 는 두 축을 합친 **요약 랭킹 점수**로만 병기 (상위: 완도·울진·양구·고흥·논산·안동·보은·영주·영양·함양)
